# Migración fiscal a CatalogMX 0.7

Esta guía describe los cambios incompatibles previstos para 0.7. La versión no
se considera publicada hasta que exista el tag y los artefactos hayan sido
verificados desde sus registros públicos.

## Modalidad 40 requiere el último SBC

El salario base solicitado y el último salario base registrado son montos
**mensuales**. El nuevo argumento obligatorio impide que una proyección se
presente como elegible cuando el salario solicitado es menor al último SBC.

Python:

```python
from catalogmx.calculators.imss import calcular_modalidad_40

resultado_general = calcular_modalidad_40(
    salario_base_cotizacion=18_000,
    ultimo_sbc_mensual=16_000,
    year=2026,
    fecha="2026-03-15",
    zona="general",
)

resultado_frontera = calcular_modalidad_40(
    18_000,
    16_000,
    2026,
    fecha="2026-03-15",
    zona="frontera",
)
```

TypeScript:

```typescript
import { IMSSCalculator } from 'catalogmx/calculators';

const resultadoGeneral = IMSSCalculator.calcularModalidad40(
  18_000, // salarioBaseCotizacionMensual
  16_000, // ultimoSbcMensual
  2026,
  '2026-03-15',
  'general'
);

const zona: 'frontera' = 'frontera';
const resultadoFrontera = IMSSCalculator.calcularModalidad40(
  18_000,
  16_000,
  2026,
  '2026-03-15',
  zona
);
```

La antigua llamada de dos argumentos no se restaura. Ambos lenguajes rechazan
valores no finitos o no positivos y un SBC solicitado menor a
`ultimo_sbc_mensual`/`ultimoSbcMensual`.

## Zona, fecha efectiva y selector CEAV

`year` selecciona el ejercicio de las tablas y `fecha` selecciona la UMA
efectiva dentro de ese ejercicio. La fecha debe pertenecer al mismo año; se
rechaza una combinación inconsistente. La UMA cambia el **1 de febrero**, por
lo que enero puede usar la vigencia iniciada el año anterior. Si se omite
`fecha`, se usa la UMA registrada para el ejercicio.

La zona salarial es obligatoria en el selector CEAV público. Use `general` para
el salario mínimo general o `frontera` para la Zona Libre de la Frontera Norte.
El SBC diario exacto al salario mínimo de su zona conserva la fila especial de
un salario mínimo; un valor inferior se rechaza.

```python
from catalogmx.calculators.imss import get_ceav_patron_rate

tasa_general = get_ceav_patron_rate(
    315.04,
    2026,
    "2026-03-15",
    zona="general",
)
tasa_frontera = get_ceav_patron_rate(
    440.87,
    2026,
    "2026-03-15",
    zona="frontera",
)
```

```typescript
import { IMSSCalculator } from 'catalogmx/calculators';

const tasaGeneral = IMSSCalculator.getCEAVPatronRate(
  315.04,
  2026,
  'general',
  '2026-03-15'
);
const tasaFrontera = IMSSCalculator.getCEAVPatronRate(
  440.87,
  2026,
  'frontera',
  '2026-03-15'
);
```

## Modalidad 10 no está auditada

Modalidad 10 permanece callable sólo por compatibilidad y su dataset tiene
estado `legacy_unverified`. No debe usarse como cálculo fiscal verificado. La
interfaz web pública la mantiene deshabilitada hasta que la auditoría de
fuentes y parámetros se cierre en el
[issue #97](https://github.com/openbancor/catalogmx/issues/97).

## Catálogos npm en Node, navegador y Workers

El tarball npm incluye los JSON de runtime que respaldan los catálogos públicos
en Node. En navegador y Cloudflare Workers no hay sistema de archivos: cargue
una vez el conjunto acotado de catálogos pequeños antes de consultar Nómina,
CFDI o bancos.

```typescript
import {
  BankCatalog,
  EstadoCfdiCatalog,
  FormaPagoCatalog,
  NominaCfdiCatalog,
  PaisCatalog,
  TipoRegimenCatalog,
} from 'catalogmx/catalogs';
import { preloadSmallCatalogData } from 'catalogmx/catalogs/preload';

preloadSmallCatalogData();

BankCatalog.isValidCode('002');
TipoRegimenCatalog.isValid('02');
FormaPagoCatalog.isValid('03');
EstadoCfdiCatalog.isValid('CMX');
PaisCatalog.isValid('MEX');
NominaCfdiCatalog.isValidClaveProdServ('84111505');
```

El preload excluye deliberadamente `ClaveProdServ` y los códigos postales
completos para no inflar el bundle. En Workers, esos catálogos grandes deben
resolverse mediante el adaptador SQLite/D1; en Node se leen desde los datos del
paquete. `NominaCfdiCatalog` no es un `ClaveProdServCatalog` parcial: es el
perfil acotado de Nómina que expone únicamente `84111505`, valor requerido por
la [guía de llenado del SAT](https://www.sat.gob.mx/cs/Satellite?blobcol=urldata&blobkey=id&blobtable=MungoBlobs&blobwhere=1461173081850&ssbinary=true).

El preflight de CI instala el tarball en directorios limpios y ejecuta el mismo
contrato mediante `require`, import ESM y un Worker real iniciado con Wrangler.

## Instalación Python reproducible

`packages/python/uv.lock` es un lock real. Para preparar el entorno de
desarrollo sin resolver versiones nuevas:

```bash
uv sync --project packages/python --locked --extra dev
```

CI ejecuta además `uv lock --check --project packages/python` para impedir que
`pyproject.toml` y el lock diverjan.
